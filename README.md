# PyCUBE-Automator
Cisco CUBE ve ISR Router platformları için geliştirilmiş Python tabanlı ağ otomasyonu.  Kurumsal bir altyapıda, ses ağlarının (Voice Networks) yönetimini, dial-peer konfigürasyonlarını ve trafik izleme süreçlerini Netmiko ile dijitalleştirerek operasyonel verimliliği  artırmayı hedefler.
